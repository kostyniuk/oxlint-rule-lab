Rule-writing reference

TL;DR — Use one vocabulary throughout the lab: node, visitor, predicate, report, plugin, and configuration.

Vocabulary

AST node
A parsed piece of syntax, such as a call or member access.
Visitor
A callback registered for an AST node type.
Predicate
The checks deciding whether this node violates the convention.
Report
The diagnostic emitted with context.report.
Plugin
The exported collection of named rules.
Configuration
The project file that loads plugins and selects rule severity.

Checklist

Write valid and invalid examples first. Inspect their ASTs. Choose a visitor. Add guards. Report the useful span. Test counterexamples. Enable the plugin. Document what the rule cannot prove.
