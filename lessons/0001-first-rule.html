01 · Report your first violation

TL;DR — A rule visits syntax nodes, checks a predicate, then reports a diagnostic. Our first win is catching a direct it.only() call.

Recognize the shape

In our example, it.only() is a CallExpression whose callee is a MemberExpression. Its object is the identifier it; its property is only. Compare the shape in ESLint Code Explorer.

CallExpression
  callee: MemberExpression
    object: Identifier (it)
    property: Identifier (only)

Run the smallest example

From the repository root, run these commands. The demo deliberately exits with an error diagnostic; tests should pass.

npm ci
npm run demo
npm test
Read the implementation rules/no-focused-tests.js

Start at CallExpression. Read each guard as a reason to allow the call. The final report highlights the property that needs attention. Metadata defines the message separately from the visitor.
