# Oxlint Resources

## Knowledge
- [Oxc: Writing JS plugins](https://oxc.rs/docs/guide/usage/linter/writing-js-plugins)
  Primary guide to visitors and RuleTester. Use for implementation and testing APIs.
- [Oxc: JS plugins](https://oxc.rs/docs/guide/usage/linter/js-plugins)
  Plugin registration and current support limits. Use before adopting a plugin in production.
- [ESLint: Custom rules](https://eslint.org/docs/latest/extend/custom-rules)
  Rule metadata, reports, options, and fixes. Use for the compatible rule contract.
- [ESLint Code Explorer](https://explorer.eslint.org/)
  Inspect parsed AST shapes. Use before selecting a visitor.
